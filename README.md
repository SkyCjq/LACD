# LACD — Lightweight Agentic Collaborative Development

**Status: under construction (bootstrap).**

This repository hosts LACD v1.0, an independent, generic, business-agnostic
governance and collaboration framework for agentic software development.

The framework itself (CLI, versioned upgrade mechanism, GitHub integration,
agent protocol, tests, docs) is being built on feature branches and delivered
via pull requests. This bootstrap commit only creates the `main` branch so the
normal branch/PR workflow can begin.

See `BOOTSTRAP.md` for why this direct commit exists.
